# Alarmnew - бот, що сповіщає про повітряну тривогу

Виконайте послідовно команди, знаходячись в директорії з Dockerfile: "docker build -t alarmnew ." і "docker run -d \
  --name alarmnew \
  --restart always \
  -e BOT_TOKEN="Ваш BOT_TOKEN телеграм бота" \
  -e ADMIN_ID="Ваш ID у телеграмі" \
  -v $(pwd)/data:/opt/alarmnew/ \
  alarmnew"

В якості джерела даних було використано -> http://ubilling.net.ua/aerialalerts/

Для оновлення даних (кожні 20 сек) використовується модуль Telethon у файлі client.py -> https://github.com/LonamiWebs/Telethon

Файл client.py необхідно додати на виконання у crontab з такими параметрами -> * * * * * python3 /path/to/client.py (більш дієвий спосіб запустити цей файл на виконання у screen)

Також на сервері, де запускається файл client.py бажано встановити 2 модулі python3 -> pip3 install python_socks та pip3 install async_timeout (щоб не отримувати помилку ConnectionError: Connection to Telegram failed 5 time(s))

Для роботи з запитами до телеграму використовуються модулі http.client та aiogram

Змінна BOT_TOKEN відповідає унікальному id Вашого телеграм бота, який можна згенерувати тут -> @BotFather

Змінні api_id та api_hash у client.py можна згенерувати тут -> https://my.telegram.org

Для зберігання даних користувачів використовується база даних sqlite3 у файлі users.db

Команди для бота:

/start - запуск бота та підписка на сповіщення, команда доступна для всіх користувачів 

/renew - циклічна перевірка поточного стану тривоги (використовується у файлі client.py для  перевірки стану налаштованої по крону, команда доступна для адміна (ADMIN_ID) - це ключова команда для роботи бота)

/check - одноразова перевірка поточного стану тривоги, команда доступна для всіх користувачів

/change_city - зміна міста/області для отримання інформації про повітряні тривоги, команда доступна для всіх користувачів

/unsub - відписатися від сповіщень, команда доступна для всіх користувачів
